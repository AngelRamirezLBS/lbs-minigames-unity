## Gate Rules

- Installer and `WildWhizMissionChecks.VerifyProvenanceLedger` enumerate every file under `Assets/App/Games/WildWhiz/Art`, `Audio`, and `Data` (excluding `.meta`).
- If any file is not listed in this ledger, verification fails and names the file.
- If any file's SHA-256 does not match the ledger, verification fails and names the file.
- Adding a temporary file without a row must fail the gate (tested via `WildWhizMissionChecks`).

## Notes

- No LogicLike art, audio, or branding was copied.
- `WildWhizCategory.asset` and `WildWhizGame.asset` are catalog data (scene wiring) and are versioned separately; their provenance is additive catalog wiring (see GameCatalog/Installer).
- `WildWhiz.unity` is a scene composition of runtime UiFactory — no embedded external media.
